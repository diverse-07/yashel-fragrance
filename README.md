# Yashel Fragrance — Haute Parfumerie & Pure Royal Attars

Official editorial website for **Yashel Fragrance**, artisanal parfumerie maison based in Greater Noida, Uttar Pradesh, India.

## Features
- **Hero Showcase**: Interactive 3D tilt crystal flacon, WebGL amber fluid caustics, and monumental typography.
- **Campaign Films**: Integrated 3-part cinematic video reel (`landing-page-1.mp4`, `landing-page-2.mp4`, `landing-page-3.mp4`).
- **Maison Hallmarks**: Pure non-alcoholic attars, 24-hour sillage, and atelier credentials.
- **Product Catalog**: Live filterable catalog with transparent pricing and direct WhatsApp concierge integration (`+91 95602 91377`).
- **Olfactory Pyramid**: Sillage breakdown across Top, Heart, and Base notes.
- **Brand Heritage**: Story of founders Ankit Goyal & Ishani Pandit.

## Deployment
Hosted seamlessly on GitHub Pages.
